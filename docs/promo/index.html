A private instruction tracker for IPS officers.

Baton (Kaavalan note) is a local-only Android app for tracking instructions between officers, contacts, and important dates. Every byte of your data lives on your device, in a SQLCipher-encrypted database. There is no cloud sync, no analytics, no telemetry.

Why Baton

Local-only by design

A thief who pulls the SD card cannot read your notes. A coercive adversary who has the device unlocked for a few minutes can be deterred with the vault mode toggle. A third-party with cloud access has nothing to access because the cloud does not exist.

Person-first, not folder-first

Notes are tied to a person (your SP, your SHO, a witness). Tap a person to see everything you ever gave them or took from them. Decay reminders nudge you to follow up with people you have not touched in 30 / 60 / 90 days.

Auditable

Every state change appends a SHA-256 hash-chained audit row. The chain is detectable on tampering; a 7-year BNSS retention window redacts the payload while preserving the chain. The threat model is documented in docs/threat-model.md.

Free, forever

Baton is a private R&D project. No ads, no premium tier, no tracking, no "we will charge you next year" roadmap. The full source is on GitHub if you want to read the threat model or audit the crypto.

Features

Voice, text, photo capture

Three modes for capturing instructions: type, talk, or shoot a photo. OCR runs on-device (ML Kit, Latin script).

Calendar link

"Add to calendar" writes an event to your phone's calendar with the due date and the people mentioned.

Decay reminders

The Today screen's decay section lists people you have not touched in 60+ days. Tap a name to send a quick "checking in" note.

Vault mode

Toggle a row to "hidden" and it disappears from every list and search. A 6-digit vault PIN gates the toggle. (Behavioural, not cryptographic — see the threat model.)

24-word recovery

Your vault passphrase is recoverable via a 24-word seed. Write it on paper, store the paper somewhere physically safe.

Daily local backup

A one-tap backup writes a JSON snapshot of all your data to the app's private storage. The file is encrypted at rest by SQLCipher.

Privacy, in one paragraph

Baton collects nothing. No name, no email, no phone, no device identifier, no location, no contacts, no calendar (events are created via the system Intent, not collected), no photos (kept on device), no audio, no files, no app activity, no web browsing, no crash logs sent off-device, no device IDs. The full privacy policy is at docs/privacy-policy.md.

Install

Download the latest APK from the releases page and sideload it. (The Play Store listing is being prepared; sideloading is the v1.x install path.)

System requirements

  • Android 8.0 (API 26) or newer.
  • ~80 MB of free storage (the APK is 71 MB; the local DB adds a few MB on top).
  • No network connection is required after install.

Verify the APK

The release APKs are signed with the production keystore committed to the repo (the project is single-author; a third-party key custodian is out of scope for v1.x). The signing fingerprint is published in each release's "Verify" section.
