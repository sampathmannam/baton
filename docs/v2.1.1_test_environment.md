# Test environment requirements (v2.1.1+)

Some unit tests need host-native libraries that are not bundled with the
project. This file documents what's required and how to install it.

## `VaultCryptoCharArrayTest` — requires `libargon2jni`

The KDF used in `VaultCrypto.deriveKey` is `com.lambdapioneer.argon2kt:1.6.0`.
That library ships **Android-ABI JNI libs only** (arm64-v8a, armeabi-v7a,
x86, x86_64). Unit tests run on a host JVM (macOS, Linux), which needs a
host-native `libargon2jni.dylib` (or `.so`) on `java.library.path`.

`argon2kt 1.6.0` has **no pure-Java fallback**. The library either
loads the JNI or throws `UnsatisfiedLinkError` on construction.

### When this matters

If you run `./gradlew :app:testDebugUnitTest` on a host without the lib,
`VaultCryptoCharArrayTest` (5 tests) will fail with:

```
java.lang.UnsatisfiedLinkError: no argon2jni in java.library.path
```

The `VaultCryptoCharArrayTest` class has a `@Before` guard
(`skipIfArgon2jniMissing`) that uses `Assume.assumeTrue` to skip the class
cleanly when the JNI is missing. So the build stays green; the 5 tests
just show up as "ignored" instead of "failed". The
`docs/v2.1.1_release_notes.md` "Risk" section flags this.

### How to actually run the tests

**macOS arm64** (Apple Silicon):
```sh
brew install argon2
# argon2 ships libargon2.dylib, not libargon2jni.dylib. The
# argon2kt SoLoader hard-codes the name "argon2jni", so you need
# either:
#   (a) build libargon2jni.dylib from the argon2kt source tree
#       (https://github.com/lambdapioneer/argon2kt — has a C/CMake
#       build for the JNI bridge), or
#   (b) symlink the brew dylib:
ln -sf /opt/homebrew/lib/libargon2.dylib /opt/homebrew/lib/libargon2jni.dylib
# then point the test JVM at the dir:
./gradlew :app:testDebugUnitTest \
  -Dorg.gradle.jvmargs="-Djava.library.path=/opt/homebrew/lib"
```

**Linux x86_64** (CI runner):
```sh
apt-get install -y libargon2-1
ln -sf /usr/lib/x86_64-linux-gnu/libargon2.so.1 \
       /usr/lib/x86_64-linux-gnu/libargon2jni.so
```

### CI

The `.github/workflows/build.yml` does not currently install the argon2
native lib. To turn the 5 tests on in CI, add a step before the
`./gradlew test` invocation:

```yaml
- name: Install libargon2jni
  run: |
    sudo apt-get update
    sudo apt-get install -y libargon2-1
    sudo ln -sf /usr/lib/x86_64-linux-gnu/libargon2.so.1 \
                /usr/lib/x86_64-linux-gnu/libargon2jni.so
```

## Other env notes

- The `app/src/main/jniLibs/` directory is intentionally **not** in the
  project. Android JNI libs ship through Gradle's per-ABI APK split
  config (`splits { abi { ... } }`) via the `argon2kt` AAR.
- For instrumented Android tests (`./gradlew :app:connectedAndroidTest`),
  the JNI is bundled in the APK and `System.loadLibrary("argon2jni")`
  resolves at install time. No host setup needed.
