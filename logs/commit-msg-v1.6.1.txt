v1.6.1: drop LLM completely

Removes all on-device LLM code:
- Llama.cpp extraction (ModelManager, LlamaBridge, LlamaError)
- Whisper.cpp voice transcription (WhisperModelManager, WhisperBridge, WhisperError)
- Extractor pipeline
- Model download UI
- Confirmation card / extract button on capture sheet
- All JNI/cpp/llama-cpp + cpp/whisper.cpp-1.6.0/ source
- All assets/model_*, assets/whisper_*, assets/grammars/, assets/prompts/
- vendorLlamaCpp + vendorWhisperCpp tasks
- externalNativeBuild + ndk { abiFilters } in app/build.gradle.kts

Voice capture now uses android.speech.SpeechRecognizer
(system service, no LLM model file). VoiceCaptureService still
owns the recognizer for the foreground notification + the
in-app Stop button.

CaptureViewModel simplified: no LlmAvailable / proposal / extract
step. Single onSaveRaw path: text in field -> tap Save ->
instruction + capture rows. Voice transcript and photo OCR feed
into the same text field.

SettingsViewModel: themeMode + setThemeMode + exportPlain +
computeStorageSizeBytes + StorageInfo.sizeBytes preserved (these
were LLM-strip casualties that needed restoration).

Settings sheet: no Models section. LLMUnavailableCard / ModelNotReadyCard /
ConfirmationCard removed. Single Save button on capture sheet.

- DatabaseModule.kt: merge conflict markers
- InstructionDao.kt: duplicate package declarations
- InstructionEntity.kt: duplicate package
- SettingsViewModel.kt: duplicate package + LLM-strip over-eager

  EmptyBrief / BriefContent
