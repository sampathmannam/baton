v1.9.1 (Honest deployability polish): 8 P0+P1 fixes from the v1.9.0 fresh-eyes critique

Closes the v1.9.0 honest deployability rating's 5 P0s + 4 P1s.

What's in the box:
  1. a11y: Today count summary is now a single TalkBack node
     (closes WCAG 1.3.1 + 4.1.2).
  2. a11y: Threat model section headers carry
     `Modifier.semantics { heading() }` (supports heading-skip).
  3. Drive row relabelled from "Back up to Google Drive" to
     "Save backup to a folder..." (the implementation uses
     SAF, not Drive REST). Tamil + Hindi translations for
     the 4 new strings.
  4. 4-screen onboarding wired using the v1.9.0
     `onboarding_screen_1..4_*` strings. First-run flow is
     now Welcome -> Privacy -> "Baton is not a notes app"
     -> Get Started.
  5. Widget badge data wired to Room:
       - `InstructionDao.countOpen()` (one indexed COUNT(*))
       - `PersonDao.countQuietSince(thresholdMs)` (60d
         default; matches the v1.9.0 widget description)
     Glance widgets reach the database via a Hilt
     `@EntryPoint` (`WidgetEntryPoint`).
  6. Per-ABI splits in `app/build.gradle.kts`:
       splits { abi { isEnable = true
         include("armeabi-v7a", "arm64-v8a", "x86", "x86_64")
         isUniversalApk = true } }
     arm64-v8a APK is now 23.4 MB (down from 68 MB
     universal). The user-installed size on a real device
     drops by 67%.
  7. 8 Play Store screenshot placeholders (1080x1920 each)
     in `docs/play-store-screenshots/`. Each has a red
     "PLACEHOLDER" stripe so a real submission cannot
     accidentally ship them. Generator at
     `app/src/test/java/com/baton/app/tools/GeneratePlayStoreScreenshots.py`.
  8. End-to-end recovery phrase test
     (`RecoveryPhraseEndToEndTest`, 4 tests) pins the
     BIP39 generation -> checksum validate -> SHA-256 hash
     pipeline. SecurePreferences round-trip is documented
     as out-of-scope (requires AndroidKeyStore; cascades
     into the other 500+ tests).

Metrics:
  - 525 -> 533 unit tests (+8)
  - 89 -> 91 test files (+2)
  - Universal APK: 71.3 -> 68 MB
  - arm64-v8a APK: NEW, 23.4 MB
  - 2 a11y warnings -> 0
  - 0 -> 4 Tamil + Hindi backup strings

No public-API or schema changes; versionCode 32 -> 33,
versionName "1.9.0" -> "1.9.1". Detailed notes in
`docs/v1.9.1_release_notes.md`.
