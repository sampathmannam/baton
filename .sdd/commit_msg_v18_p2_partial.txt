v1.8.0 (PROD-READINESS-P2-#4..#7): Phase 2 P0s partial (audit chain, retention, branding, eFIR bridge)

Phase 2 (department pilot) work in progress:

P0 #4 (Hash chain audit): DONE. New AuditChainEventEntity +
AuditChainEventDao + AuditChainWriter + AuditChainVerifier.
SHA-256 chain anchored at GENESIS_HASH, per-row prevHash +
thisHash computed from payload + prevHash + signingKey.
The v13->v14 migration adds the audit_chain_events table.
Wiring the SyncEngine to append on every state change is
a follow-up; the chain infrastructure is testable in
isolation. 6/6 tests pass.

P0 #5 (Retention): DONE. New RetentionPolicy (BNSS defaults:
7y audit, 3y captures, 3y dates, 7y instructions) +
RetentionWorker (daily periodic, runs on a 24h WorkManager
schedule). Captures + dates hard-deleted; audit chain
REDACTED (payload cleared, hash chain preserved). 4/4 tests
pass.

P0 #6 (Branding): DONE. New BrandingConfig reads
buildConfigField BRAND_NAME / BRAND_DEPARTMENT / BRAND_ICON,
overridable via gradle -Pbrand.* flags. Settings -> About
section shows the per-build brand. Default APK is unchanged
("Kaavalan note").

P0 #7 (CCTNS/ICJS/eFIR bridge): DONE. New CctnsBridge interface
+ NoOpCctnsBridge default. Every method returns
BridgeResult.NotConfigured so the call sites fail LOUDLY (no
fake "succeeds" implementation). 5/5 tests pass.

Phase 2 P0 remaining: #1 (multi-user crypto), #2 (sync
conflict UI), #3 (role model). Plan:
docs/PRODUCTION_READINESS_PLAN.md.
