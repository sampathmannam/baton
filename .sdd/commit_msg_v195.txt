v1.9.5 (Compact DecayRow): drop Mark recent button, add swipe-right + long-press

The v1.9.4 horizontal-sibling layout still left the "Mark recent"
TextButton eating ~80dp of horizontal space, which forced the
days-quiet text to ellipsize as "haven't touched in 93 d..." on
a 1080px device. v1.9.5 drops the button entirely and moves the
affordance to:

  1. Swipe-right past a 96dp threshold (Material 3 standard
     list-item side-effect action). The gesture is wired with
     `pointerInput { detectHorizontalDragGestures }` on a
     Box that wraps the Card; the background layer shows a
     quiet "Mark recent" tertiary-container label as the user
     drags. On `onDragEnd`, if the offset exceeds the threshold
     the per-row `onMarkRecent` fires, the DAO touch completes
     async, the row leaves the Quiet-a-while list, and the
     existing UndoController surfaces the standard
     "Marked as recent. [Undo]" snackbar.
  2. Long-press → `combinedClickable` on the Card + a
     `ModalBottomSheet` with the person's name as the title
     and "Mark recent" + "Cancel" actions. The discoverable
     escape hatch for users who don't know the swipe gesture.

The status pill (`ReachOutPill`) is the only right-side control
now. The left text column gets the full available width, so
"haven't touched in 93 days" renders without ellipsis.
