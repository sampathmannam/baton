# Baton v1.6.4 — synthetic-data drive plan

## Context

Baton v1.6.3 (commit `3f6e2d2`) shipped an Obsidian-style UI/UX refresh
and a new app icon (05-shieldmark). v1.6.3-r2 (`75d2719`) drove 4 systematic-debugging
fixes on a small 12-person / 36-instruction fixture and verified them.

Two problems remained:
1. The v1.6.2-era fixture was only partially loaded — only K. Suresh had 1 OPEN
   instruction, all other 11 persons had 0. The systematic-debugging pass
   couldn't drive-verify T45 ("Carried over" pill colour) because no
   CARRIED_OVER instructions existed in the partial data.
2. The 12-person / 36-instruction fixture is too small to surface the
   variety of UI issues that exist in a real-world data set.

## v1.6.4 fixes layered on top of v1.6.3-r2

1. **Bottom nav Settings un-tappable fix** (MainActivity.kt)
   - Added hardcoded 48dp bottom padding on top of `navigationBarsPadding()`.
   - Pushes the Compose nav above the system 3-button nav on emulators where
     the inset (63px) is less than the actual nav height (126px).

2. **3 more count+noun plurals** (strings.xml + 3 call sites)
   - `decay_days_quiet` → "haven't touched in 1 day" / "in N days"
   - `morning_brief_carried_over` → "1 carried over" / "N carried over"
   - `bulk_snooze_banner` → "1 quiet contact" / "N quiet contacts"
   - 3 multi-count strings (todays_win_summary, settings_storage_value,
     settings_dev_loaded) flagged for future refactor.

3. **Synthetic data fixture expanded** (assets/synthetic-data.json)
   - 12 → 55 persons, 36 → 200 instructions, 7 → 50 captures, 12 → 16 tags.
   - All status / urgency / priority / direction / source distributions
     covered.
   - 5 deterministic edge-case persons + many random edge cases.

4. **Settings → Developer "Clear & reload" button** (SettingsSheet.kt)
   - Forces a clean re-load of the synthetic fixture. The original
     "Load test data" button kept the same effect, but the new label
     is explicit about wiping existing data.

5. **Refresh strings.xml counts** (settings_dev_body updated to 55/200/50/16).
